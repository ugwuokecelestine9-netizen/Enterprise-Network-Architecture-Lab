ENTERPRISE NETWORK INFRASTRUCTURE

Purpose:
A scalable, secure and highly available multi-site enterprise network designed to demonstrate real-world networking concepts including VLANs, Inter-VLAN Routing, OSPF, HSRP, DHCP, DNS, ACLs, NAT/PAT, Firewall Security and Network Redundancy.

Design Goal:
Secure communication, departmental segmentation, high availability, centralized services and controlled network access.
